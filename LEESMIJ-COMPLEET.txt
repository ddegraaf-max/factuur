EASYINVOICE — COMPLETE UPDATE (definitieve drop-in)
===================================================
Dit is ÉÉN pakket met de nieuwste versie van ALLE wijzigingen. Volgorde maakt
niet meer uit: pak dit uit op de ROOT van je factuur-repo, laat het alle
bestanden overschrijven, commit en deploy. Klaar.

============================================================
STAP 1 — UITPAKKEN
============================================================
Uitpakken op de root van de 'factuur'-repo (waar app/, resources/, routes/,
config/ staan). Alles overschrijven. Commit via GitHub Desktop -> Railway
deployt.

============================================================
STAP 2 — DATABASE MIGREREN (VERPLICHT)
============================================================
   php artisan migrate
Voegt toe:
  - tabel 'reminder_logs' (verloop van herinneringen/aanmaningen)
  - kolom 'accountant_email' op companies (BCC boekhoudkantoor)

============================================================
STAP 3 — RAILWAY VARIABELEN
============================================================
   APP_VERSION="Easy 1.0.0"
   SESSION_SECURE_COOKIE=true
   # Bot-bescherming (leeg = uit, invullen = aan; VITE_ moet gelijk zijn aan SITEKEY):
   TURNSTILE_SITEKEY=
   TURNSTILE_SECRET=
   VITE_TURNSTILE_SITEKEY=
   # Incasso (optioneel; standaarden staan al goed):
   INCASSO_CLAIMS_EMAIL=j.backers@armaere.nl
   INCASSO_CC=info@creditline.nl

============================================================
STAP 4 — CLOUDFLARE CACHE LEGEN  (belangrijk!)
============================================================
Cloudflare bewaart je pagina's. Zie je na de deploy nog de oude versie
(bijv. "Inloggen" onder het logo op mobiel), leeg dan de cache:
   Cloudflare dashboard -> je domein -> Caching -> Configuration -> Purge Everything
Daarna op je telefoon hard verversen of een privé-tabblad gebruiken.

Snelle check of de nieuwe versie live is (op een computer):
   easyinvoice.nl -> rechtsklik -> Paginabroncode weergeven -> Ctrl+F op "nav-mobile"
   Gevonden = nieuwe versie live. Niet gevonden = nog oude versie (cache/deploy).

============================================================
STAP 5 — CRON VOOR AUTOMATISCHE HERINNERINGEN
============================================================
Laravel's planner draait niet vanzelf op Railway. Zet één van deze:
  A) Een scheduled service die elke minuut draait:  php artisan schedule:run
  B) Of een dagelijkse cron die draait:             php artisan invoices:remind
Zonder dit gaan de automatische herinneringen/aanmaningen niet uit.
